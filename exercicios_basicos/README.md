## Lista de exercícios básicos

A cada exercício concluído, será adicionada uma descrição explicando o que acontece no código e qual é o seu funcionamento.

1. **[Exercício 01](01_exercicio.py)** → Se o produto de dois números for menor ou igual a 1000, retorna o produto. Caso contrário, retorna a soma dos dois números.

2. **[Exercício 02](02_exercicio.py)** → É escolhido um intervalo de números para serem somados. A soma sempre considera o número atual e o número anterior.

3. **[Exercício 03](03_exercicio.py)** → Uma palavra é digitada e são exibidos somente os caracteres que estão nos índices pares, utilizando *slice* (`[início::pulo]`).

4. **[Exercício 04](04_exercicio.py)** → Uma palavra e um índice são digitados. São exibidas as letras da palavra a partir do índice escolhido, utilizando *slice* (`[índice::]`).

5. **[Exercício 05](05_exercicio.py)** → Dois valores são escolhidos para serem trocados de posição, utilizando empacotamento e desempacotamento de tuplas (`a, b = b, a`). O exercício também propõe reescrever a solução utilizando uma lista.
