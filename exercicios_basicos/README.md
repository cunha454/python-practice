## Lista de exercícios básicos

A cada exercício concluído, será adicionada uma descrição explicando o que acontece no código e qual é o seu funcionamento.

01. **[Exercício 01](01_exercicio.py)** → Se o produto de dois números for menor ou igual a 1000, retorna o produto. Caso contrário, retorna a soma dos dois números.

02. **[Exercício 02](02_exercicio.py)** → É escolhido um intervalo de números para serem somados. A soma sempre considera o número atual e o número anterior.

03. **[Exercício 03](03_exercicio.py)** → Uma palavra é digitada e são exibidos somente os caracteres que estão nos índices pares, utilizando *slice* (`[início::passo]`).

04. **[Exercício 04](04_exercicio.py)** → Uma palavra e um índice são digitados. São exibidas as letras da palavra a partir do índice escolhido, utilizando *slice* (`[índice::]`).

05. **[Exercício 05](05_exercicio.py)** → Dois valores são escolhidos para serem trocados de posição, utilizando empacotamento e desempacotamento de tuplas (`a, b = b, a`). O exercício também propõe reescrever a solução utilizando uma lista.

06. **[Execício 06](06_exercicio.py)** → Um número é escolhido, seu fatorial é calculado e por fim exibe o resultado.

07. **[Execício 07](07_exercicio.py)** → Uma lista de frutas é escolida, seu 2 elemento é removido com `pop()` e adicinado mais uma fruta a final da lista com `append()`.

08. **[Execício 08](08_exercicio.py)** → Uma palavra é escolida, ela é invertida usando `[::passo]` e a palavra é exibida de forma invertida.

09. **[Execício 09](09_exercicio.py)** → Uma palavra é escolhida e, por meio de um laço `for` com `in`, cada letra é verificada para saber se pertence ao grupo de vogais. Ao final, a quantidade total de vogais é exibida.

10. **[Execício 10](10_exercicio.py)** → Uma sequência de números é digitada e, com o uso das funções `max()` e `min()`, é possível descobrir o maior e o menor valor da sequência, sem precisar fazer um laço.

11. **[Execício 11](11_exercicio.py)** → Uma sequência de números repetidos é escolhida e, por meio do `set()` tranforma a lista em conjunto, consequentemente removendo as duplicidades.

12. **[Execício 12](12_exercicio.py)** → Retorna True se o primeiro elemento `[0]` for igual ao último `[-1]`. Caso contrário, retorna False.

13. **[Execício 13](13_exercicio.py)** → Verifica quais elementos de uma lista são divisível por 5, usando `%` em laço.

14. **[Execício 14](14_exercicio.py)** → Analiza quantas vezes determinada palavra foi mencionda em uma frase usando o `count()`.

15. **[Execício 15](15_exercicio.py)** → Cria um laço de repetição onde cada número é repetido uma quantidade de vezes igual ao seu próprio valor.

16. **[Execício 16](16_exercicio.py)** → Verifica se o número é um palíndromo convertendo-o em string usando `str()` e invertendo-o com `[::-1]`.

17. **[Execício 17](17_exercicio.py)** → Cria uma nova lista combinando os números ímpares da primeira lista com os números pares da segunda.

18. **[Execício 18](18_exercicio.py)** → Inverte um número utilizando apenas da matemática, extraindo o último algarismo por meio do resto da divisão e removendo-o com divisão inteira até que o número chegue a zero.

19. **[Execício 19](19_exercicio.py)** → Calcula o imposto de renda com base no valor da renda informada, utilizando as estruturas condicionais `if`, `elif` e `else`.

20. **[Execício 20](20_exercicio.py)** → Cria uma tabuada utilizando laços de repetição aninhados. Utilizagit o parâmetro `end="\t"` da função `print()` para organizar em tabulações.

21. **[Execício 21](21_exercicio.py)** → É criado um laço de repetição em que, a cada ciclo, o número diminui em 1 até chegar a zero, formando uma pirâmide invertida.

22. **[Execício 22](22_exercicio.py)** → É usado um laço de repetição para fazer o processo de exponenciação manualmente, sem usar o operador `**`, que já faz sozinho.

23. **[Execício 23](23_exercicio.py)** → Verifica se um número é um palíndromo utilizando operações matemáticas, seguindo a mesma lógica do exercício 18, e comparando o resultado com o número original.

24. **[Execício 24](24_exercicio.py)** → Gera a sequência de Fibonacci até atingir o valor informado, utilizando uma lista que armazena os números e adiciona novos elementos a partir da soma dos dois últimos valores da sequência.

25. **[Execício 25](25_exercicio.py)** → Verifica se o ano informado é um ano bissexto. Com base no fato de que um ano bissexto precisa ser divisível por 4, e não pode ser divisível por 100, a não ser que seja divisível por 400.
